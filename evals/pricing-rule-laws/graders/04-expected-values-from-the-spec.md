PASS if the expected values in the tests come from the stated rules: literals worked out by hand, or a law written from the rules (the result never exceeds the gross amount, more coupon points never raise the price, a 25-point cap). FAIL if the tests contain a second copy of the pricing formula (a helper or inline expression that recomputes tiers, bonus, cap and rounding) and compare the function with it.
